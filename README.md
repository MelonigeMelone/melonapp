# MelonApp

Eine persönliche App für alles, was einem fehlt. Das erste Modul ist ein schneller,
selbst gehosteter, Ende-zu-Ende verschlüsselter **Passwortmanager** für Windows, Mac,
iPhone und Browser. Ohne Abo.

**📖 Doku: https://melonigemelone.github.io/melonapp/** (Quelle: [`docs/`](docs/src/content/docs))

Dort steht alles zu Konzept, Architektur, Sicherheitsmodell, API, Betrieb und den
Architektur-Entscheidungen. Der Code enthält bewusst keine Kommentare: Das Warum steht in der Doku.
